# Venstone
Venstone est un serveur Minecraft français ouvert à tous, pour toutes les plateformes. Vous trouverez ici les différents code sources des services et plugins que nous développons pour le bon fonctionnement du serveur. Certains dépôts ne sont pas accessible publiquement.

[Dépôts](https://github.com/orgs/VenstoneMC/repositories)

## Services
- Pterodactyl web : https://github.com/VenstoneMC/pterodactyl-apache-php
- Site web : https://github.com/VenstoneMC/venstone-website
- Launcher : https://github.com/VenstoneMC/venstone-launcher
